# Engineering

## User-invoked

- **[devsetup](./devsetup/SKILL.md)** - provisiona ambiente Windows.
- **[orchestrator](./orchestrator/SKILL.md)** - inicia governanca, roadmap, Issues, execucao e QA.
- **[skill-router](./skill-router/SKILL.md)** - escolhe o fluxo sem executar.

## Model-invoked

Estas skills podem ser compostas por um fluxo explicitamente iniciado. Side effects continuam sujeitos aos gates da propria skill.

- **[code-review](./code-review/SKILL.md)** - revisa Standards e Spec.
- **[diagnose](./diagnose/SKILL.md)** - diagnostica por reproducao e hipoteses falsificaveis.
- **[grill-feature-with-docs](./grill-feature-with-docs/SKILL.md)** - alinha feature existente, codigo e docs.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** - alinha design, dominio e ADRs.
- **[implement](./implement/SKILL.md)** - executa uma GitHub Issue aprovada.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** - encontra oportunidades de aprofundamento.
- **[prototype](./prototype/SKILL.md)** - responde design com codigo descartavel.
- **[qa-analyst](./qa-analyst/SKILL.md)** - aplica o portao final antes de PR.
- **[query-docs](./query-docs/SKILL.md)** - consulta documentacao versionada.
- **[research](./research/SKILL.md)** - pesquisa fontes primarias.
- **[roadmap](./roadmap/SKILL.md)** - mantem Epics ligadas ao GitHub.
- **[scaffold-mvp](./scaffold-mvp/SKILL.md)** - inicializa MVP dentro de fluxo autorizado.
- **[secure-e2e](./secure-e2e/SKILL.md)** - valida fluxos e barreiras de seguranca.
- **[setup-skills](./setup-skills/SKILL.md)** - configura governanca e tracker GitHub.
- **[tdd](./tdd/SKILL.md)** - executa red-green-refactor por seam.
- **[to-issues](./to-issues/SKILL.md)** - publica slices verticais apos aprovacao.
- **[to-prd](./to-prd/SKILL.md)** - publica PRD a partir do contexto.
- **[triage](./triage/SKILL.md)** - move Issues pela maquina de estados.
- **[zoom-out](./zoom-out/SKILL.md)** - mapeia modulos e callers.
